# Probability & Statistics question collection — change log

Version 1.1.0 (previous 1.0.0, commit ca62eb8). One row per question ID that changed. Unchanged IDs are omitted; the full map, including unchanged IDs, is `revisions.json` in the import package.

| Status | Count |
|---|---:|
| unchanged | 1229 |
| revised | 206 |
| retired | 0 |
| new | 0 |

Rules: IDs of corrected questions are kept (status revised). An ID whose skill or standard changes is retired and never reused; the replacement questions get new IDs (status new). Sets added after publication take the next free set number; branches added to an existing set take the next free branch number. Numbers need not be consecutive.

## Review findings

| Code | Finding |
|---|---|
| R01 | Answer uniqueness: every item has exactly one correct answer (duplicate correct histogram panels, a tie between strategies, a random-digit count that had more than one defensible answer) |
| R02 | Statistical statements and models: claims that summary statistics alone cannot support, causal and sampling wording, and the population a conclusion applies to |
| R03 | Simulation decisions: each decision rule states its model, the tail counted and the cutoff |
| R04 | Missing local givens and answer-form mismatches: each question restates what it uses, and the asked form matches the key |
| R05 | Probability models stated bank-wide: fairness, independence, random selection, replacement, guessing and payoffs (applied to every item found by the new check 28, not only the review's examples) |
| R06 | Precision and numeric wording: keys written to the stated precision; trailing-zero handling by the game checker documented (check 30) |
| R07 | Wording that overstated a claim (absolute statements, interval overlap read as proof) |
| R08 | Assessment quality: a MAIN item that only repeated its givens |
| R09 | Supplied simulation results labeled as hypothetical |

## 1.0.0 (2026-10-24) — first release

- New collection: 54 question sets, 1,435 questions, namespace `PS` (uids such as `PS:S12-B2-Q3`).
- CORE strand: every non-(+) High School Statistics & Probability standard (25 standards, 41 sets).
  ADVANCED EXTENSION strand: every (+) standard, HSS-CP.B.8, HSS-CP.B.9 and all of HSS-MD, with HSS-MD.B.5.a and
  HSS-MD.B.5.b separate (10 standards, 13 sets).
- Every question is graded automatically by the game (short answer, multiple choice, true/false only); every short-answer
  key was run through the game's own answer checker.
- 58 synthetic datasets, documented in `DATASETS.md`.
- Errors found and fixed before release are listed in `VALIDATION.md` ("Manual review").

There is no earlier version, so no question was revised or retired. Later versions will list every changed ID here.

# Probability & Statistics — set plan

Sets were written in four domain batches, in this order, after the standards inventory (`src/standards.py`, 35 standards, 54 subskills). Each set focuses on one subskill. Strand "advanced" marks the (+) standards (Advanced Extension).

Every set has a MAIN of 5 questions, 2-3 BACKWARD branches of 5, FORWARD 1 and FORWARD 2 (5 each). The full branch map with progression types is in `COVERAGE.md` section 4.

# Algebra II question collection — change log

Version 1.1.0 (previous 1.0.0, commit e3bf665). One row per question ID that changed. Unchanged IDs are omitted; the full map, including unchanged IDs, is `revisions.json` in the import package.

| Status | Count |
|---|---:|
| unchanged | 2417 |
| revised | 108 |
| retired | 0 |
| new | 0 |

Rules: IDs of corrected questions are kept (status revised). An ID whose skill or standard changes is retired and never reused; the replacement questions get new IDs (status new). Sets added after publication take the next free set number; branches added to an existing set take the next free branch number. Numbers need not be consecutive.

## Review findings

| Code | Finding |
|---|---|
| M01 | No question may need a person or a drawing surface to grade: every shown-work item (proofs, derivations, explanations, divisions; 53) and every drawing item (50 graphs on a blank grid and 5 graphs with a written equation) is redesigned as multiple choice |
| M02 | S42-F1-Q2 asked for a cubic with a positive y-intercept that touches the x-axis at 3 and falls to the right; no cubic has all of these features (touching at 3 and falling to the right make it negative between -1 and 3). The condition is now a negative y-intercept. |

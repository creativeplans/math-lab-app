# Logic collection: source-genre map

The three "Game Show References for Logic" decks (15 puzzles each) were used only to choose puzzle GENRES. No deck question, wording, picture or answer is copied: every question in this collection is original, and none is a classic published riddle. The table lists each deck puzzle (deck, puzzle number), its genre in a few words, and the set or sets that teach that genre with new questions.

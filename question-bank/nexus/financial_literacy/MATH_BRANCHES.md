# Financial Literacy — Math Prerequisite Branches

A math branch is a backward section with `"kind": "math"` and a `ref` to a MAIN skill that is already in Untangle The Nexus. It has no questions of its own; the game sends the student to that skill. Every ref was checked against `engine/fl_math_catalog.json`, which is copied from the game's `content/*/curriculum.json` (Grades 3-8 and Algebra I). No ref points to a course that is not installed, no set lists the same link twice, and no link points back into Financial Literacy (the importer does not resolve links into the course's own folder).

The branch fires only under the game's existing rule: **3 or fewer correct out of 5** on MAIN. The student then works every backward section of the set in the order listed.

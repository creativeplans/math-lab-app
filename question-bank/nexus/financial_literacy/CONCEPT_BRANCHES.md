# Financial Literacy — Concept Prerequisite Branches

A concept branch is a backward section with `"kind": "concept"`: five simpler questions about a money idea the MAIN skill rests on. They carry their own questions because the importer does not resolve links between sets of the same course. Concept branches never link to other sets, so there are no circular or broken references. Each set lists its concept branch first and its math links after it, so a student reviews the money idea and then the arithmetic.

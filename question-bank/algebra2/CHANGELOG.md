# Algebra II question collection — change log

Version 1.2.0 (previous 1.1.0, commit e9b2d6c). One row per question ID that changed. Unchanged IDs are omitted; the full map, including unchanged IDs, is `revisions.json` in the import package.

| Status | Count |
|---|---:|
| unchanged | 1615 |
| revised | 910 |
| retired | 0 |
| new | 30 |

Rules: IDs of corrected questions are kept (status revised). An ID whose skill or standard changes is retired and never reused; the replacement questions get new IDs (status new). Sets added after publication take the next free set number; branches added to an existing set take the next free branch number. Numbers need not be consecutive.

## Review findings

| Code | Finding |
|---|---|
| R01 | Every question must be graded automatically by Untangle The Nexus: no person judges wording, drawings or work. Short answers that only a person (or exact wording) could grade became multiple choice or true/false; every remaining short answer got one answer line per part, the precision or form in the question, and a key the game's answer checker accepts |
| R02 | Statistics: each question states its own model and conventions (null model, tail, 5% cutoff, the 2-standard-deviation margin of error, independence, fair devices) and never treats a common result as proof |
| R03 | Specific mathematical corrections named in the review (values, domains, restrictions, wording) |
| R04 | Missing information: the question now states every given it needs, so it stands alone |
| R05 | Coverage: a focused step-function set (HSF-IF.C.7.b) and set titles that match the assessed response |
| R06 | Grading notes of reasoning items now say what is wrong with each other choice |
| R07 | Multiple-choice length cue removed: other choices were rewritten with specific errors so that the correct choice is not much longer than every other choice |
| R08 | Other wording or choice revisions found while rewriting (conditions stated, a second defensible answer removed) |
